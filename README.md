## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **One-Click Install** | No Python, no terminal — just download and start creating |
| **Text-to-Image** | Generate high-quality images from natural language descriptions |
| **Image Editing** | Inpainting and outpainting for seamless photo manipulation |
| **Model Library** | Download curated community models directly inside the app |
